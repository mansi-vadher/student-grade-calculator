# Student Grade Calculator

A beginner-friendly Python program that calculates a student's academic performance based on marks obtained in five subjects.

## Features
- Accepts marks for five subjects
- Calculates total marks
- Calculates percentage
- Determines grade
- Displays pass/fail status

## Technologies Used
- Python

## Concepts Practiced
- User input
- Variables
- Arithmetic operations
- Conditional statements
- Basic programming logic

## How to Run
1. Download `student_grade_calculator.py`
2. Make sure Python is installed
3. Run the file using:

```bash
python student_grade_calculator.py
```
